### Sobre

Sou Engenheiro de Software Sênior na **[Pismo](https://pismo.io) / Visa**, trabalhando
com plataformas financeiras de alta performance: arquiteturas distribuídas com picos
de **6.000 TPS** e mais de **200 milhões de registros por dia**, em stack reativa na
AWS com pipelines de dados em Apache Spark e Databricks.

Passei pelo suporte técnico antes do desenvolvimento. Entender como um sistema falha
na prática mudou a forma como projeto software — e isso continua guiando minhas decisões.
